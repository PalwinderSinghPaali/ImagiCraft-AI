Installing the Application

To set up the project locally on your machine, follow these commands in your terminal:

# 1. Clone the repository

git clone https://github.com/PalwinderSinghPaali/ImagiCraft-AI.git

cd ImagiCraft-AI

# 2. Install required dependencies

npm install

2

Obtaining an OpenAI API Key

In order for the application to generate images, you need to configure an OpenAI API key on your server:

  1. Navigate to the OpenAI Developer Platform.
  2. Log in or register for a developer account.
  3. Go to the API Keys section from the left navigation panel (or visit platform.openai.com/api-keys).
  4. Click the "Create new secret key" button.
  5. Provide a name for the key (e.g., ImagiCraft AI) and click Create.
  6. Copy the generated secret key immediately. (Note: You will not be able to view it again once the modal is closed).
3

Adding Billing Credits to OpenAI

Important Note: API usage is billed separately from consumer ChatGPT Plus subscriptions. You must add credit balances directly to your developer account API billing, even if you are already a paying ChatGPT Plus user.

Follow these steps to add credit balance to your account:

  1. Go to the Billing Dashboard at platform.openai.com/settings/organization/billing.
  2. Click on "Add to credit balance" or "Purchase credits".
  3. Enter the amount of credits you wish to add (minimum $5 USD).
  4. Enter your credit card or payment billing details and complete the transaction.
  5. Make sure your credit balance reflects the added amount so your API requests are authorized.
4

Configuring Environment & Starting the Server

1. Copy the example environment file inside your root directory:

cp .env.local.example .env.local

2. Open .env.local and add your OpenAI API Key:

OPENAI_API_KEY=sk-proj-yourOpenAiApiKeyHere...

3. Launch the development server:

npm run dev

4. Open your browser and navigate to http://localhost:3000.
