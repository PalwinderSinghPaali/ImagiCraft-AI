# ImagiCraft AI — Text-to-Image Generator

ImagiCraft AI is a modern, responsive full-stack Next.js application built using TypeScript, Tailwind CSS, and the OpenAI SDK to generate high-quality images using **DALL-E 3**.

## Features

- **Prompt Presets**: Quick-start templates for multiple artistic styles (e.g., Cyberpunk, Fantasy, Anime, Photorealistic, 3D Render, Surrealism).
- **DALL-E 3 Customization**: Tune options such as Aspect Ratio/Size (`1024x1024`, `1024x1792`, `1792x1024`), Quality (`standard`, `hd`), and Style (`vivid`, `natural`).
- **Interactive Artboard**: Shows detailed loading states, revised prompt outputs generated by DALL-E, copy URLs, and direct download buttons.
- **Image Proxying**: Includes a custom route `/api/proxy-image` that pipes the images through the server, completely eliminating CORS download issues.
- **Generation History**: Saves previous generations locally using `localStorage` so you never lose your generated artwork.

## Getting Started

### 1. Configure the Environment

Copy the environment example file to `.env.local`:

```bash
cp .env.local.example .env.local
```

Open `.env.local` and add your OpenAI API Key:

```env
OPENAI_API_KEY=sk-proj-yourOpenAiApiKeyHere...
```

### 2. Run the Development Server

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to experience the application.
